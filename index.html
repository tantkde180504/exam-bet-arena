Hướng Dẫn Sử Dụng & Đưa Lên GitHub Pages

Cách Sử Dụng Web Lên Kèo:

  1. Bước 1: Nhấn "Tạo Kèo Mới" hoặc "Chỉnh Kèo Nhanh" để nhập thông tin 2 bạn bè, chọn kèo Đậu/Rớt, mốc điểm và phần thưởng.
  2. Bước 2: Nhấn "Sao Chép Link Chia Sẻ" để gửi cho bạn bè. Mọi thông tin kèo đã được mã hóa vào đường link URL.
  3. Bước 3: Nhấn "Tải Ảnh Chứng Nhận" để xuất file ảnh PNG biên bản đóng mộc đỏ đăng lên Facebook/Zalo.
  4. Bước 4: Khi có điểm thi thực tế, bấm tab "Mở Bát Kết Quả", nhập điểm để hệ thống tính toán thắng thua và kích hoạt pháo hoa!

Cách Host Miễn Phí Trên GitHub Pages:

  1. Tạo 1 repository mới trên GitHub (Ví dụ: keo-thi-cu).
  2. Đẩy toàn bộ các file trong thư mục này lên branch main.
  3. Vào Settings -> Pages, tại mục Branch chọn main rồi nhấn Save.
  4. Trang web của bạn sẽ hoạt động ngay tại đường dẫn: https://tên-github.github.io/keo-thi-cu/!
